# Bike Sales Analysis

## Overview

Excel-based analysis of customer bike purchase data to identify factors influencing bike purchases.

## Tools

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel formulas

## Data Preparation

- Removed duplicate customer records
- Standardized categorical values
- Created age brackets
- Prepared the dataset for analysis

## Analysis

The analysis focuses on:

- Average income by gender and purchase status
- Bike purchases by commute distance
- Bike purchases by age group

## Dashboard

An interactive Excel dashboard was created with:

- Total Customers
- Bikes Purchased
- Purchase Rate
- Interactive slicers
- Supporting charts

## Key Findings

- 1,000 unique customers were analyzed.
- 481 customers purchased a bike.
- Overall bike purchase rate was 48.10%.
- Customers commuting 0–1 miles formed the largest commute group.
- Middle-aged customers represented the largest age group.
